# Nature-style Scientific Writing

## Core Principles
- Clarity over complexity; avoid unnecessary jargon.
- Active voice where possible; precise passive voice for methods.
- Logical flow: Introduction → Methods → Results → Discussion.
- Data-driven claims; no overstatement without evidence.

## Workflow
1. Outline the core hypothesis and key findings.
2. Draft sections with strict word limits (Nature: ~1500 words, 4-5 figs/tables).
3. Ensure each paragraph has one clear topic sentence.
4. Methods: reproducible, concise, cite key protocols/software.
5. Results: describe facts, avoid interpreting too early.
6. Discussion: link to existing literature, state limitations.

## Constraints
- Avoid AI-typical phrasing (e.g., "In conclusion", "It is worth noting").
- No hallucinated references; only cite real, verified papers.
- Use exact p-values, n values, and statistical tests.
- Maintain human-like variation in sentence length.
